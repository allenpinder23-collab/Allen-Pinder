# Island Girl Bahamian Cuisine: Operating System

Open Claude Code **in this folder** (`cd island-girl && claude`) so it loads CLAUDE.md, the six director agents in `.claude/agents/`, and the `website-builder` and `seo-optimizer` skills in `.claude/skills/`.

- CLAUDE.md: rules, stack, money rules, executive team
- HANDOFF.md: history and open questions
- 00_Executive/: roadmap, decision log, one folder per director
- 01 to 08: working folders (see CLAUDE.md section 5)
- 07_Finance/ is git-ignored except placeholders. Bank statements never get committed.

Say "board meeting" to get a status brief from every director.
